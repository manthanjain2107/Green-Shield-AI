# 🛡️ GreenShield AI – Multi-Disaster Prediction System

**GreenShield AI** is an intelligent, AI-driven platform designed to **predict natural disasters** such as **floods and forest fires** using Machine Learning.  
It empowers communities and authorities with early risk warnings, enabling timely preventive actions to save lives and reduce damage.

---

## 🌍 Features

- 🔮 Predicts **flood** and **wildfire** risks using trained Random Forest models.  
- ⚙️ Uses **real-time and historical data** for accurate forecasting.  
- 🌦️ Integrates with **weather and environmental parameters** such as temperature, humidity, rainfall, and water level.  
- 🔁 Switch easily between **Flood Mode** and **Wildfire Mode**.  
- 🧠 Provides **risk scores and probabilities** with visual indicators.  
- 💡 Built with **Streamlit** for an interactive, modern dashboard UI.
